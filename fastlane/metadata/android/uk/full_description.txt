SDAI — відкритий мобільний клієнт генерації зображень зі ШІ для Android та iOS. Він дає художникам, ентузіастам і розробникам один зрозумілий workflow для промптів, налаштувань генерації, перегляду результатів і перемикання між потрібними провайдерами.

ChatGPT OAuth (бета) дозволяє увійти напряму й створювати зображення з gpt-image-2, зокрема послідовно в пакетному режимі. Увімкніть вхід за кодом пристрою в обліковому записі ChatGPT або робочому просторі. Сесія зберігається в захищеному сховищі пристрою; вихід доступний у налаштуваннях провайдера. Зовнішній проксі та API-ключ не потрібні. Неофіційна інтеграція залежить від доступу облікового запису й обмежень сервісу.

OpenAI-compatible підтримує генерацію за текстом, ID моделі вашого сервера, розмір зображення та послідовні пакети. Укажіть повний API-префікс; ключ потрібен лише тоді, коли його вимагає сервер.

Обирайте backend під задачу:
- власний сервер AUTOMATIC1111 або SwarmUI
- OpenAI-compatible
- community-воркери AI Horde
- Hugging Face Inference API
- OpenAI Images API
- Stability AI / DreamStudio API
- локальна дифузія на Android через ONNX, де доступно

SDAI тримає під рукою знайомі налаштування генерації зображень: positive і negative prompt там, де вони підтримуються, seed, steps, CFG scale, розмір зображення, sampler, вибір моделі або engine, LoRA, embeddings, hypernetworks, Img2Img, Inpaint, batch generation і параметри окремих провайдерів.

Застосунок створений для мобільного workflow і не прив'язує вас до одного хмарного сервісу. Можна використовувати власний сервер, підключити API keys для hosted providers або генерувати на пристрої з підтримуваними Android local engines. Згенеровані зображення зберігаються у вбудованій галереї з деталями, зумом, sharing, нативним збереженням/експортом і ZIP export.

Без реклами. Без телеметрії. Без lock-in до одного провайдера. SDAI — community-driven free software: код можна переглядати, issues можна репортити, переклади можна покращувати, а мобільну генерацію зображень можна розвивати разом із проєктом.

Примітка: цей листинг F-Droid стосується Android FOSS build. iOS використовує спільний мобільний досвід SDAI для remote generation providers, а частина local diffusion можливостей залишається Android-only.

SDAI — незалежний проєкт. Він не пов’язаний зі Stability AI чи Stable Diffusion, не схвалений і не спонсорується ними.
