ChatGPT OAuth

Sign into ChatGPT and generate directly from your phone.

Sign in

  1. Enable device-code login in your ChatGPT account security settings. Your workspace may require administrator approval.
  2. Open SDAI Configuration and choose ChatGPT OAuth, immediately after OpenAI.
  3. Tap Sign in with ChatGPT. SDAI displays a one-time code.
  4. Tap Open the sign-in page and enter the code at https://auth.openai.com/codex/device. Enter only a code for a login you started yourself.
  5. Return to SDAI and tap Connect after authorization completes.

The code expires after fifteen minutes. Cancel, leave the configuration screen or restart the app to discard a pending attempt. A failed or cancelled replacement login preserves the previous completed session.

Generate images

This Beta provider supports text-to-image with gpt-image-2, a prompt, positive width/height and sequential batches. Accepted dimensions, image access and limits depend on the account and upstream service. Actual output dimensions are recorded in the shared gallery.

Chat, image editing, negative prompts, samplers, steps, CFG scale, seed and quality controls are unsupported. The integration uses an unofficial backend and may require updates when the service changes.

Sessions and sign-out

Tokens stay in Android Keystore-backed encrypted storage or device-only iOS Keychain. Refresh runs inside the bundled feature. No external proxy, Node process, desktop credential import or API key is needed. Credentials are not sent through queued generation jobs or stored in gallery metadata.

Open provider configuration and tap Sign out to delete the local session. Signing out, switching accounts or selecting another provider stops affected work; an older queued job cannot use the replacement account. Signing out locally does not revoke other OpenAI sessions.

Troubleshooting

If protected session data cannot be read, unlock the device and return to SDAI. The app retries initialization without stopping account-state updates. If the stored session is corrupt, use Reset local session in provider configuration, then sign in again. Reset deletes the local envelope without decoding it; it never falls back to unprotected storage.

  • Device login unavailable: enable device-code login in account security settings or ask the workspace administrator.
  • Expired code: start sign-in again. Keep SDAI open or return promptly; operating systems can suspend background polling.
  • Session expired: sign in again if refresh is rejected.
  • Account/provider changed: submit a new generation using the selected account.
  • Rate limit, timeout or unsupported dimensions: check access/limits and retry deliberately. SDAI does not automatically replay an image request after an ambiguous network failure.

Other OpenAI sources

OpenAI uses a regular API key. OpenAI-compatible connects to a user-hosted server or external proxy. All three sources keep their configuration independent.

See the privacy policy and consumed API contract. The Kotlin module adapts device authorization from OpenAI Codex and direct image transport from openai-oauth, with Apache-2.0 notices retained.
