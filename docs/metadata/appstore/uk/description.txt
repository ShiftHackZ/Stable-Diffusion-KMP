SDAI — відкритий застосунок для генерації зображень зі ШІ для тих, кому потрібна свобода вибору провайдера на мобільному пристрої.

ChatGPT OAuth (бета) дозволяє увійти напряму й створювати зображення з gpt-image-2, зокрема послідовно в пакетному режимі. Увімкніть вхід за кодом пристрою в обліковому записі ChatGPT або робочому просторі. Сесія зберігається в захищеному сховищі пристрою; вихід доступний у налаштуваннях провайдера. Зовнішній проксі та API-ключ не потрібні. Неофіційна інтеграція залежить від доступу облікового запису й обмежень сервісу.

OpenAI-compatible підтримує генерацію за текстом, ID моделі вашого сервера, розмір зображення та послідовні пакети. Укажіть повний API-префікс; ключ потрібен лише тоді, коли його вимагає сервер.

Пишіть промпти, налаштовуйте параметри, підключайте image provider, яким уже користуєтесь, і зберігайте результати в чистій локальній галереї. SDAI створений для художників, ентузіастів, prompt engineers і розробників, яким потрібен мобільний workflow навколо їхнього поточного generation setup.

Для гнучкого AI art workflow:
